# Smart News Feed Ranking & Personalization System

A console-based DSA project developed in **C** that ranks news articles based on popularity, recency, and user preferences to generate a personalized Top-K news feed.

### Key Features
- News addition, deletion, and searching
- Personalized news ranking
- Top-K feed generation using Max Heap
- Trending news identification
- Reading history management

### DSA Concepts
Arrays, Structures, Hash Tables, Max Heap, Queue, Linked List, and Sorting.

### Technologies
- C Programming
- GCC Compiler
- Data Structures and Algorithms

### Execution
```bash
gcc main_simplified.c -o news_feed
./news_feed
```
